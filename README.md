# 🚗 GoCar - Premium Luxury & Everyday Car Rental

A modern, responsive, and feature-rich car rental web application designed with a sleek luxury dark theme, glassmorphism aesthetics, and intuitive user experiences.

![GoCar Rental Platform](images/logo.svg)

---

## ✨ Features

- **🚗 Interactive Car Fleet Gallery**: Explore a curated collection of executive sedans, sport coupes, and hypercars with real-time specs (Transmission, Fuel/Engine type, Capacity, Daily Rates).
- **🔍 Brand & Live Budget Filter**: Dynamic filtering by car brand (*Audi, Mercedes, BMW, Ferrari, Skoda*), availability status, or daily budget threshold.
- **📅 Booking & Reservation Modal**: Interactive pop-up reservation form allowing customers to select dates, pickup locations, and submit booking requests seamlessly.
- **📱 Fully Responsive Design**: Seamless layout adaptation across Desktop, Tablet, and Mobile screens with an animated mobile drawer menu.
- **📍 Location & Contact**: Interactive Google Maps location hub, showroom details, and responsive contact form with toast notification feedback.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic tags, accessibility standards (`aria-labels`), video background integration.
- **CSS3**: CSS Custom Properties (Variables), CSS Grid, Flexbox layouts, glassmorphism (`backdrop-filter`), smooth transitions.
- **JavaScript (ES6+)**: Modular DOM manipulation, dynamic filtering algorithms, modal event listeners, interactive mobile navigation.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Bilyz26/gocar-car-rental-website.git
   ```
2. **Navigate into the directory**:
   ```bash
   cd gocar-car-rental-website
   ```
3. **Open in browser**:
   - Double click `index.html` or serve with any local server (e.g. Live Server in VS Code).
